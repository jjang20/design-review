# design-review (Template DRS 시험 키트)

**Template DRS**(슬라이드 덱 디자인 검수 도구)의 Claude 플러그인 저장소입니다.

## 지금 지원하는 범위

- 이 버전(0.0.x)은 **빈 플러그인**입니다. **어떤 디자인도 판정하지 않습니다.** 설치 · 설정 · 점검 과정만 확인합니다.
- 슬라이드 외 형식(포스터 · 명함 · 플라이어 · SNS · 썸네일)은 **아직 지원 범위가 아닙니다.**

시험에 참여하시는 분은 안내받은 문단 하나만 Claude에 붙여 넣으면 됩니다. 이 저장소를 직접 열어 볼 필요는 없습니다.

- 플러그인: `plugin/` (스킬 `setup` · `doctor` · `design-review`, 설정과 점검을 한 번에 진행하는 `kit/drs_kit.py`)
- 마켓플레이스 목록: `.claude-plugin/marketplace.json`
- 시험 중 보내는 정보: 시험자 코드, 버전, 컴퓨터 종류, 단계별 통과/실패와 걸린 시간, 커넥터 연결 여부, 만족도와 불편한 점의 **고정 선택지**뿐입니다. 보내기 전에 보낼 내용을 전부 보여 드리고 한 번 동의를 받으며, 동의하기 전에는 아무것도 보내지 않습니다. 이름 · 이메일 · 계정 주소 · 슬라이드 내용 · 직접 쓴 글은 담지 않고, 담을 칸도 없습니다.
